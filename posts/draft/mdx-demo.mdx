`.mdx` 는 Markdown 안에서 컴포넌트를 쓰고 JS 식을 넣을 수 있다. 이 글은 초안이라 `astro dev` 에서만 보인다.

<Callout type="tip" title="컴포넌트">
  `Callout` 은 `src/components/mdx/Callout.astro` 다. 안쪽도 **Markdown** 으로 쓴다.
</Callout>

JS 식: 답은 {answer} 이다.

## 수식

인라인 $a^2 + b^2 = c^2$ 와 블록 수식:

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

## 코드 블록

```ts
const square = (x: number): number => x * x;
```
